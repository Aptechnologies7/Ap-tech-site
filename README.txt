AP TECHNOLOGIES WEBSITE
=======================

Pages:
- index.html        Home
- services.html     IT services
- hospitality.html Hospitality technology
- clients.html      Clients & brand ecosystem
- estimator.html    Interactive requirements estimator (not a price quote)
- locations.html    Service locations
- contact.html     Contact form / inquiry

HOW TO RUN
1. Extract this ZIP to a folder.
2. Open index.html in a browser, or use VS Code Live Server for a local web server.
3. Upload all files and the assets folder together to your hosting provider.

IMPORTANT
- The inquiry form opens WhatsApp with a prefilled message. The visitor must press Send in WhatsApp.
- No backend or database is included.
- Please verify client names, testimonials, service coverage, authorized-dealer claims and any numerical claims before publishing.
- This version uses Tailwind-free custom CSS and external Google Fonts / Font Awesome CDN resources.
